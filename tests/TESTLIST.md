# Список тестов

## Идентификаторы и ключевые слова

- [x] Разбор идентификаторов: `alice Bob C00L D_2 x`
- [x] `var x: int = 0` — var, int
- [x] `func foo() -> int { return 0 }` — func, return, ->
- [x] `struct Point { x: int, y: int }` — struct, int
- [x] `bool flag = true` — bool, true
- [x] `false` — false
- [x] `if x > 0 { return 1 } else { return 0 }` — if, else
- [x] `while x < 10 { x = x + 1 }` — while
- [x] `for (i = 0; i < n; i = i + 1) { print(i) }` — for
- [x] `string name = ""` — string
- [x] `func hello() -> void { }` — void
- [x] `IF` — регистрозависимость ключевых слов
- [x] `int _x` — подчеркивание в начале не идентификатор
- [x] `int x_` — подчеркивание в конце идентификатора
- [x] `int x_y` — подчеркивание внутри идентификатора

## Литералы

- [x] Разбор литералов целых чисел: `0 1234 56789`
- [x] Разбор строк: `"" "0" "Hello, world!"`
- [x] Разбор простых escape-последовательностей: `"\n\"\\"`
- [x] Неизвестная escape-последовательность: `"\x"` — Error
- [x] Максимум int: `2147483647`
- [x] Переполнение int: `2147483648` — Error
- [x] Ведущий ноль: `007` — Error
- [x] Отрицательное число: `-42` — минус и положительный литерал
- [x] Минус перед нулем: `-0`
- [x] Минус перед максимумом int: `-2147483647`
- [x] Незакрытая строка: `"abc` — Error

## Недопустимые символы

- [x] `@` — Error
- [x] `#` — Error
- [x] `$` — Error
- [x] `Я` — не-ASCII символ, Error
- [x] `✈️` - два Error \u2708 и ufe0f

## Операторы, разделители и скобки

- [x] `x + y / (10 - z * 2)` — операторы `+, -, *, /`, скобки `()`
- [x] `a < b | a > c | b = c` — операторы `<, >, =, |`
- [x] `a <= b & b >= c & a == c` — операторы `<=, >=, ==, &`
- [x] `point.x = v[0]` — операторы `.`, `=`, скобки `[]`
- [x] `struct Point { x: int, y: int }` — скобки `{}`, разделители `':', ','`
- [x] `(foo(x);0)` — разделитель `;`
- [x] `a != b` — оператор `!=`
- [x] `!flag` — оператор `!`
- [x] `->` — стрелка как один токен
- [x] `-->` — два токена `-` и `->`

## Пробелы и комментарии

- [x] Пропуск пробельных символов: `' '`, `'\t'`, `'\r'`, `'\n'`, `'\f'`
- [x] Комментарии: `/* ... */`
- [x] Вложенные комментарии: `/* ... /* ... */ */`
- [x] Однострочный комментарий: `// ...`
- [x] Пустой ввод
- [x] Только пробельные символы
- [x] Только комментарии
