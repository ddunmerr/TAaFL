# Список тестов

## Класс Lexer
### Идентификаторы и ключевые слова

- [ ] Разбор идентификаторов: `alice Bob C00L D_2 x`
- [ ] Объявление переменной: `var x: int = 0` — var, int
- [ ] Ветвление: `if a then b else c` — if, then, else
- [ ] Цикл с условием: `while x < 10 do x = x + 1` — while, do
- [ ] Цикл с итератором: `for i in 1..10 do print(i)` — for, in
- [ ] Объявление функции: `func foo() -> int { return 0 }` — func, return
- [ ] Объявление структуры: `struct Point { x: int, y: int }` — struct
- [ ] Логические литералы: `true false`
- [ ] Ключевые слова строго в нижнем регистре: `IF` — это Identifier, а не If
- [ ] Предопределённые идентификаторы `print readInt readString` — это Identifier, не ключевые слова

### Литералы

- [ ] Разбор целых чисел: `0 1234 56789`
- [ ] Разбор строк: `"" "0" "Hello, world!"`
- [ ] Разбор escape-последовательностей: `"\n\t\"\\"`
- [ ] Незакрытая строка → токен Error
- [ ] Целое число больше `long.MaxValue` → токен Error

### Операторы

- [ ] Арифметические операторы: `x + y - z * w / v`
- [ ] Операторы сравнения: `a < b`, `a <= b`, `a > b`, `a >= b`, `a == b`, `a != b`
- [ ] Логические операторы: `a && b`, `a || b`, `!a`
- [ ] Оператор присваивания: `x = 10`

### Разделители и скобки

- [ ] Круглые скобки: `( )`
- [ ] Фигурные скобки: `{ }`
- [ ] Квадратные скобки: `[ ]`
- [ ] Запятая, точка с запятой, двоеточие, точка: `, ; : .`
- [ ] Стрелка `->` разбирается как один токен (правило максимального совпадения), а не как `-` и `>`

### Пробелы и комментарии

- [ ] Пропуск пробельных символов: `' '`, `'\t'`, `'\r'`, `'\n'`, `'\f'`
- [ ] Однострочный комментарий: `// ...`
- [ ] Многострочный комментарий: `/* ... */`
- [ ] Вложенный многострочный комментарий НЕ поддерживается
