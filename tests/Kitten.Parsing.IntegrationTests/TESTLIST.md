# Список тестов

## `ProgramExecutionTests`

- [x] Пустая программа: `func main() -> void { }` -> пустой вывод
- [x] Комментарий между токенами: `func main() -> /* коммент */ void { }` -> пустой вывод
- [x] Комментарий после блока main: `func main() -> void { } /* коммент */ ` -> пустой вывод
- [x] Печать литерала: `print(5);` -> `5`
- [x] Приоритет умножения над сложением: `print(10 + 2 * 5);` -> `20`
- [x] Скобки меняют порядок: `print((10 + 2) * 5);` -> `60`
- [x] Левая ассоциативность вычитания: `print(10 - 3 - 2);` -> `5`
- [x] Унарный минус: `print(-5);` -> `-5`
- [x] Унарный минус и скобки: `print(-(2 + 3));` -> `-5`
- [x] Два унарных минусов `func main() -> void { print(--5); }` -> `5`
- [x] Три унарных минусов `func main() -> void { print(---5); }` -> `-5`
- [x] Деление: `print(20 / 4);` -> `5`
- [x] Несколько инструкций: `print(1); print(2);` -> `1`, `2`
- [x] Выражение как инструкция: `2 + 3; print(6);` -> `6`
- [x] Ввод в выражении: `print(readInt() + 1);` с вводом `7` -> `8`
- [x] Встроенная функция `min`: `print(min(3, 7));` -> `3`
- [x] Встроенная функция `max`: `print(max(3, 7));` -> `7`
- [x] Встроенная функция `sqr`: `print(sqr(5));` -> `25`
- [x] Квдрат отрицательного числа: `print(sqr(-5));` -> `25`
- [x] Комбинированное выражение: `print(min(2, 3) + max(4, 5) * sqr(2));` -> `22`
- [x] Пример из задания: `print(10 + 7 * (2 * 3 + 4) + 5 + -5);` -> `80`
- [x] Умножение на отрицательное число: `print(10 * -2);` -> `-20`
- [x] Вложенные функции print(min(min(1, 2), 3)) -> `1`
- [x] Вложенные функции print(sqr(sqr(2))) -> `16`
