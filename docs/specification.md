# Спецификация языка Kitten

## Введение

Kitten — минималистичный императивный учебный язык программирования, предназначенный для изучения разработки интерпретатора. Программа на Kitten состоит из одного файла с расширением `.kit` в кодировке UTF-8 и имеет точку входа — функцию `main`.

Язык строго типизирован: поддерживаются числовой тип `int`, строковый тип `string` и логический тип `bool`. Переменные объявляются явно с указанием типа. Поддерживаются ветвления, циклы и последовательное выполнение инструкций в блоке. Язык поддерживает одномерные массивы и пользовательские структуры с именованными полями. Поддерживается процедурный стиль: пользователь может объявлять функции, в том числе не возвращающие значение; классов в языке нет.

Вывод выполняется инструкцией `print`, ввод — встроенными функциями `readInt` и `readString`.

### Связь с другими языками

По базовому синтаксису Kitten напоминает языки C-семейства: фигурные скобки для блоков, ; после инструкций, комментарии // и /* */.    

Часть черт заимствована из конкретных языков:

объявление переменных var x: int = 0; — в стиле Kotlin и TypeScript;        
объявление функций func f() -> int — в стиле Swift и Rust;        
синтаксис массивов int[] — в стиле C#.   

## Лексика

Исходный файл на Kitten — это последовательность символов Unicode в кодировке UTF-8. Файл может содержать пробельные символы, комментарии, идентификаторы, ключевые слова, литералы, операторы и разделители. Пробельные символы и комментарии игнорируются при разборе.  

При разборе действует правило максимального совпадения: лексема выбирается как самая длинная из возможных.

### Пробельные символы

| Символ | Обозначение | Код ASCII |
|---|---|---|
| Пробел | SP | 0x20 |
| Горизонтальная табуляция | HT | 0x09 |
| Перенос строки | LF | 0x0A |
| Возврат каретки | CR | 0x0D |
| Form feed | FF | 0x0C |

### Комментарии

Комментарии начинаются с `//` и продолжаются до конца строки либо начинаются с `/*` и заканчиваются на `*/`. Вложенные комментарии допустимы.

### Идентификаторы

Идентификатор — это последовательность букв латинского алфавита (`a`–`z`, `A`–`Z`), десятичных цифр (`0`–`9`) и символов подчёркивания `_`, которая начинается с буквы.   

Регистр идентификаторов имеет значение.  

### Ключевые слова

Ключевые слова — это последовательности букв, зарезервированные для однозначности синтаксических правил; они не являются идентификаторами. Список ключевых слов:   

`bool`, `true`, `false`, `if`, `else`, `for`, `while`, `func`, `var`, `int`, `string`, `return`, `struct`, `void`

Ключевые слова записываются строго в нижнем регистре; последовательности вида `IF`, `If`, `iF` не являются ключевыми словами и распознаются как идентификаторы.

### Литералы

**Логические литералы.** Логические литералы — это ключевые слова `true` и `false`.  

**Литералы целых чисел.** Литерал целого числа — это последовательность десятичных цифр:

- Литерал не может начинаться с `0`, если он содержит более одной цифры.
- Литералы не содержат знак и всегда обозначают положительные числа.
- Не допускаются литералы целых чисел, значение которых не попадает в диапазон 32-битных целых положительных чисел.     

**Литералы строк.** Литерал строки — это последовательность символов Unicode и escape-последовательностей, заключённая в двойные кавычки `"..."`. Поддерживаются escape-последовательности: `\n` (перевод строки), `\"` (двойная кавычка) и `\\` (обратный слеш).   
Строковый литерал может занимать несколько строк.



### Операторы

`=`, `==`, `!=`, `<`, `<=`, `>`, `>=`, `&`, `|`, `!`, `+`, `-`, `*`, `/`

### Разделители

`[`, `]`, `(`, `)`, `{`, `}`, `,`, `;`, `:`, `.`, `->`

`.` используется для доступа к полю структуры. `->` используется для указания возвращаемого типа функции, `:` используется в объявлениях переменных `var x: int`  и в полях структур.   


## Синтаксис

Синтаксис языка Kitten описан грамматикой в нотации EBNF (диалект ISO/IEC 14977).  

Грамматика ниже описывает только подмножество языка, реализуемое в текущей итерации.

```ebnf
(* Программа: точка входа — функция main *)
program = main_function_declaration, end_of_file ;

(* Объявление функции main: func main() -> void { ... } *)
main_function_declaration = "func", "main", "(", ")", "->", "void", block ;

(* Блок инструкций *)
block = "{", { statement }, "}" ;

(* Инструкция: вывод числа или выражение *)
statement = print_statement
    | expression_statement ;

(* Вывод в стандартный поток вывода*)
print_statement = "print", "(", expression, ")", ";" ;

(* Выражение как инструкция *)
expression_statement = expression, ";" ;

(* Выражения *)
expression = additive_expression ;

additive_expression = multiplicative_expression,
    { ("+" | "-"), multiplicative_expression } ;

multiplicative_expression = unary_expression,
    { ("*" | "/"), unary_expression } ;

unary_expression = { "-" }, primary_expression ;

primary_expression = integer_literal
    | function_call
    | "(", expression, ")" ;

(* Вызов встроенной функции *)
function_call = read_int_call | min_max_call | sqr_call ;

read_int_call = "readInt", "(", ")" ;

min_max_call = ("min" | "max"), "(", expression, ",", expression, ")" ;

sqr_call = "sqr", "(", expression, ")" ;
```

### Ассоциативность операторов

| Написание | Семантика | Особенности |
|---|---|---|
| + | Сложение чисел | Левая ассоциативность |
| - | Вычитание чисел | Левая ассоциативность |
| * | Умножение чисел | Левая ассоциативность |
| / | Деление чисел | Левая ассоциативность |

Приоритеты операторов (в порядке убывания приоритета):  
1. Умножение и деление: * и /
2. Плюс и минус: +, -   

`print(expression);` Выводит значение выражения с переводом строки
`min(int, int)` Вычисляет минимум из двух чисел
`max(int, int)` Вычисляет максимум из двух чисел
`sqr(int)` Вычисляет квадрат числа
`readInt()` Cчитывает целое число из стандартного ввода
